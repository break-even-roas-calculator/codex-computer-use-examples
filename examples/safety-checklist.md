# Pre-flight checklist for Codex Computer Use

Computer Use is the broadest trust boundary of the three Codex surfaces.
Run through this list before approving a new app or starting a task.

## Before approving an app

- [ ] Is there a plugin or MCP server that does this without a GUI? Use it instead.
- [ ] Does the task need only a browser tab? Use the Chrome extension instead.
- [ ] Is this one app or one flow? Split multi-app tasks unless the flow genuinely spans them.

## Before starting the task

- [ ] Sensitive apps that are not part of the task are closed.
- [ ] The prompt names the app and includes a boundary sentence.
- [ ] The prompt says what to do if a password, payment or security prompt appears (stop and ask).

## While it runs

- [ ] Review each permission prompt rather than approving in bulk.
- [ ] Stay present for anything financial, account, payment, credential, privacy or system-security related.
- [ ] On macOS it may keep working in the background; check in rather than assuming it finished.

## Afterwards

- [ ] Read the agent's summary of actions and compare with the final screenshot.
- [ ] Revoke approval for apps you do not expect to use again.
